# Personal Web Site

Portfolio of Bedirhan Aydın — freelance full-stack developer.

<a href="https://bedirhanaydin-dev.web.app/">Visit my personal site</a>

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · Motion

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/ (HTML prerendered)
firebase deploy  # publish dist/ to Firebase Hosting (project: bedirhanaydin-dev)
```

All CV content (experience, projects, skills, education) lives in `src/data/cv.ts` — update it there and the sections re-render.
